Static HTML mockups for **cillianscreatures.com**.

## Deploy to Hostinger
1. In hPanel go to **File Manager** for the domain `cillianscreatures.com`.
2. Upload the contents of this folder into the public root (usually `public_html` or the domain folder).
3. Ensure `index.html` is in the root so it loads at the domain.

You can also point Hostinger’s Git deployment (if available on your plan) at this repo and set the public directory to `cillianscreatures`.
